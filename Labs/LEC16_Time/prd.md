# LEC16 시간 실습 확장 요구사항

## 목표

방향키로 달리는 캐릭터 위에 `bird_animation.png`를 사용하는 새 떼를 추가하고, 스페이스바로 발사하는 공을 강의자료의 마지막 장과 같이 공중 포물선으로 날린다.

## 새 떼

- 화면 위쪽에 새 10마리를 동시에 표시한다.
- 스프라이트 시트 5열×3행에서 실제 비행 프레임 14개를 순서대로 사용하고, 비어 있는 마지막 칸은 건너뛴다.
- 각 새의 애니메이션 위상을 달리해 같은 날갯짓 프레임이 한꺼번에 반복되지 않게 한다.
- 새 떼는 경과 시간 기준으로 좌우 이동하고, 화면 안에서 방향을 바꾸어 왕복한다.
- 이동 방향이 바뀌면 스프라이트도 좌우 반전한다.
- 달리는 캐릭터와 기존 배경·입력·발사 동작을 유지한다.

## 공중 향해 볼 발사

- 스페이스바로 발사한 공은 캐릭터가 바라보는 수평 방향으로 이동하며, 초기 수직 속도로 위쪽으로 상승한다.
- 중력은 `9.8 * (10 / 0.3)` 픽셀/초², 초기 수평·수직 속도는 각각 300픽셀/초로 둔다.
- 프레임 간격을 초 단위로 사용해 속도와 위치를 갱신한다.
- 화면 바깥 또는 지면 기준선(`y = 40`)에 닿은 공을 게임 월드에서 제거한다.
- 작은 공과 큰 공 모두 스프라이트 반경을 기준으로 화면 및 지면 충돌을 처리한다.

## 검증 기준

- 새 떼의 개수는 항상 10마리이고, 15번째 빈 프레임은 재생하지 않는다.
- FPS가 달라져도 같은 경과 시간 동안 이동 거리와 애니메이션 재생 속도가 일관된다.
- 새는 화면 경계에서 사라지지 않고 반대 방향으로 계속 비행한다.
- 공은 발사 직후 위로 상승하고, 최고점 이후 중력에 의해 하강한다.
- 공은 지면에 닿거나 화면을 벗어나면 월드에서 제거된다.

## 구현 논리

### 새 스프라이트와 날갯짓

원본 이미지 918×506은 5열×3행이다. 열과 행의 시작점뿐 아니라 끝점도 각각 `column * width // 5`, `(column + 1) * width // 5`처럼 정수 비례 계산한다. 나누어떨어지지 않는 픽셀을 인접 칸이 빠짐없이 나누어 가지며, 프레임 인덱스는 0~13으로 제한해 마지막 빈 칸을 프레임으로 취급하지 않는다. Pico2D 클리핑은 왼쪽 아래 기준이므로 위에서 계산한 행 경계는 `image_height - bottom_edge`로 변환한다.

애니메이션은 14 FPS, 14프레임 순환으로 계산한다. 각 새의 프레임은 `int(animation_time * FPS + phase) % 14`이며, 위상은 `index * 14 / 10`으로 나누어 새들이 한꺼번에 같은 날갯짓을 하지 않게 한다. 시간 누산은 한 주기 길이로 나머지 연산해 긴 실행 중에도 값이 계속 커지지 않는다.

### 새 떼 비행

열 마리는 선두 한 마리, 좌우 대칭으로 뒤따르는 네 쌍, 후미 한 마리의 V자 좌표로 구성한다. 방향이 오른쪽일 때 후미 좌표는 선두보다 왼쪽이며, 왼쪽 비행에서는 수평 오프셋에 방향 부호를 곱해 대형을 반전한다. 프레임도 Pico2D의 수평 반전 옵션으로 부리 방향을 이동 방향에 맞춘다.

새 떼의 중심 이동은 `속도 * frame_time`으로 계산한다. 이동 후 중심을 `[min_x, max_x]` 구간의 두 배 길이 주기로 접어 넣는 삼각파 반사를 사용하므로, 한 프레임에 경계를 지나쳐도 위치를 잃거나 화면 밖으로 순간이동하지 않는다. 1600픽셀 화면에서 대형의 최대 수평 오프셋 275, 새 너비 64, 여백 36을 고려해 중심 범위를 343~1257로 제한한다. 세로 중심은 420이고 최대 수직 오프셋은 136이므로 새는 600픽셀 화면 안에서 캐릭터 위에 머문다.

플레이 모드는 캐릭터를 일반 오브젝트 레이어에 먼저 등록한 후 새 떼를 등록한다. 같은 레이어에서 등록 순서대로 그려지므로 새 떼가 캐릭터보다 앞에 겹쳐 그려지며, 실제 배치는 캐릭터 위쪽 하늘에 놓인다.

### 공중 발사 공

발사 방향은 캐릭터의 `face_dir` 부호로 정하고, 초기 속도는 수평·수직 각각 초당 300픽셀이다. 강의자료의 중력 `9.8 * (10 / 0.3)`은 픽셀/초² 단위로 사용한다. 각 프레임에서 먼저 `x += vx * dt`, `y += vy * dt - 0.5 * g * dt²`를 적용한 뒤 `vy -= g * dt`로 갱신한다. 이는 일정한 중력 아래 포물선 운동을 프레임 시간에 맞춰 누적하는 방식이다.

공은 이미지 종류에 따라 반경 10.5 또는 20.5픽셀을 사용한다. 화면 경계를 반경만큼 완전히 벗어나거나 공의 아래쪽이 지면선 `y = 40`에 닿으면 `game_world`에서 제거한다.
