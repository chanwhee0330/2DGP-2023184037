# Drill #8 애니메이션 뷰어

`animation_viewer.py`는 화면 중앙에서 다음 6개 애니메이션을 순서대로 재생합니다.

- `IDLE` 6프레임
- `WALK` 8프레임
- `RUN` 8프레임
- `JUMP` 12프레임
- `SLASH` 6프레임
- `THRUST` 4프레임

각 애니메이션은 5회 반복한 뒤 마지막 프레임에서 1초 정지하며, 모든 동작이 끝나면 처음부터 무한 반복합니다. `Esc` 키 또는 창 닫기로 종료할 수 있습니다.

## 추가 구현 사항

- 애니메이션마다 서로 다른 프레임 수를 지원합니다.
- 투명 여백을 제거한 실제 캐릭터 영역을 프레임별 `(left, bottom, width, height)`로 지정했습니다. 따라서 프레임마다 폭과 높이가 다른 복잡한 Sprite Sheet를 사용합니다.
- 잘라 낸 영역의 크기가 달라도 원래 128×128 격자의 중심을 기준으로 위치를 보정하여 캐릭터가 흔들리지 않습니다.

## AI 활용

AI를 이용해 Sprite Sheet의 알파 채널을 분석하여 각 프레임의 실제 영역을 구하고, 재생 상태 전환 및 좌표 보정 코드를 작성했습니다.

## 실행

`pico2d`가 설치된 환경에서 다음 명령을 실행합니다.

```powershell
cd LEC08
python animation_viewer.py
```
